# Handmade System — Fındık Universe

## Principle
Fındık Universe must look illustrated, observed and deliberately composed — never like a generic AI-generated dashboard or a pile of decorative components.

“Handmade” does not mean visually messy. It means every scene has an authored point of view: a focal moment, meaningful texture, restrained colour and a reason for each object.

## Visual north star
Warm storybook city life:
- soft paper, ink, painted texture and quiet daylight
- tactile edges and imperfect-but-intentional details
- generous negative space around Fındık
- one coherent scene, not a collage of icons

Avoid:
- neon, cyan/teal glow, glassmorphism and aurora gradients
- excessive floating pills, generic card grids and AI-looking ornament
- emoji as final character or scene art
- random style changes between adventures

## Scene composition
Every scene needs:
1. Fındık as the clearest focal point.
2. One readable action or emotional beat.
3. One environmental story detail.
4. A calm area for copy and controls.
5. A mobile portrait crop that remains legible at 375px wide.

## Character animation
Start with believable restraint:
- idle breath or subtle sway
- blink at irregular intervals
- one tap reaction with a clear recovery
- walking only when a location change happens
- celebration only when an earned moment occurs

Do not loop loud animations continuously. Motion exists to make Fındık feel present, not to demand attention.

## UI craft
- Controls must be thumb-sized and named with plain Turkish.
- UI chrome recedes; scene and character lead.
- Use texture and shape sparingly, only where they support the story.
- Respect iPhone safe areas and reduced-motion preferences.
- Each screen must have one obvious next action.

## Review questions
Before approval, ask:
- Would this still be recognisable with all text removed?
- Is Fındık unmistakably the hero?
- Does the scene feel authored rather than generated?
- Does the UI add clarity without competing with the illustration?
