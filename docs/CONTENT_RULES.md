# Content Rules

## Source of truth
Character facts live in `CHARACTER_BIBLE.md`. Product behavior lives in `PRODUCT_VISION.md`. Do not silently invent missing canon.

## Adventure format
Each adventure has: id, place, icon, title, short hook, story, reward XP, unlockable sticker, memory caption and visual theme.

## Copy
- Turkish first.
- Short enough for an iPhone screen.
- Cute + witty, not childish nonsense.
- Ordinary places become disproportionately important missions.

## Progression
Progress rewards exploration; it must not punish absence. No daily streak loss, countdown pressure or purchases.

## Memory cards
A completed adventure creates one durable memory entry with completion date and caption. Replaying is allowed but must not duplicate the same canonical memory.

## Assets
Canonical character art goes under `assets/character/`; adventure scenes under `assets/adventures/`; stickers under `assets/stickers/`. Temporary placeholders must be clearly identified and easy to replace.
