# Sprint 01 — First Real Visit

## Objective
Deliver one complete, installable and emotionally convincing Fındık interaction loop.

## In scope
- Production PWA metadata and app icons
- Vercel deployment connection and mobile verification
- First approved canonical character asset package
- Home-scene integration for idle, blink and tap response
- Tramvay Macerası: one focused interactive task, success state and replay
- Memory card, XP and sticker reward persistence
- Reduced-motion, keyboard/dialog and mobile overflow checks

## Out of scope
- Full world map
- Cloud accounts or backup
- Wardrobe
- Other four adventures beyond maintaining their existing prototype state
- AI generation
- Payments, ads or social features

## Acceptance criteria
- Installs from Safari to an iPhone home screen with a real Fındık icon.
- Opens in standalone portrait mode without clipped safe-area controls.
- First online visit enables an offline reload.
- Fındık is canonical art, not emoji, in the home scene.
- The Tramvay adventure includes an interaction that can succeed or retry.
- Completing it once gives exactly one canonical memory, one reward and one sticker.
- Replaying does not duplicate the canonical memory or reward.
- At 375px and 430px viewport widths, there is no horizontal overflow.
- The experience remains understandable with reduced motion enabled.

## Evidence required before closing
- Production URL
- iPhone install screenshot/video
- Offline reload confirmation
- 375px and 430px QA result
- Asset approval record
- Completed Tramvay loop test result
