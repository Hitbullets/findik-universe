This folder is the project’s operating system. Product decisions, character canon, visual craft standards and release gates live here before they are encoded in the app.

## Working agreement
- No new feature ships without a place in the product vision and rules.
- No visual asset ships without character-canon and handmade checks.
- A prototype is never called production-ready without the technical gates in this folder.
- When a decision changes, update the relevant document and log it in DECISIONS.md.
