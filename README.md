# Fındık Universe 🐾

Fındık Universe, iPhone'a kurulabilen ve ilerlemeyi cihazda saklayan küçük bir interaktif karakter dünyasıdır. Fındık dokunuşlara tepki verir, Tramvay Macerası'na çıkar, anı ve sticker kazanır.

## Güncel teslim profili

İlk teslim sürümü bilinçli olarak dardır:

1. Tek production macerası Tramvay'dır.
2. İlerleme yalnız cihazda tutulur; hesap, bulut yedekleme ve uzaktan feedback kapalıdır.
3. Ev, Tramvay, Albüm, Kasa ve yerel Ayarlar teslim kapsamındadır.
4. Diğer maceralar, hikâyeler, Harita ve Adventure Studio yalnız internal beta kapsamındadır.
5. Başarılı build tek başına teslim kanıtı değildir; mobil, offline, erişilebilirlik ve fiziksel iPhone kapıları ayrıca geçmelidir.
